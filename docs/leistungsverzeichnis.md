# Leistungsverzeichnis

**Projekt:** Website Steffen Vorholt Comedy — www.steffenvorholt.de
**Auftraggeber:** Steffen Vorholt
**Ausführung:** GrowCore — Lennard Kuss
**Stand:** 29.07.2026

---

## 1. Konzept & Beratung

| Pos. | Leistung |
|---|---|
| 1.1 | Erstgespräch, Zielklärung und Abstimmung, was die Website leisten soll |
| 1.2 | Aufbau und Gliederung der Website (Seitenstruktur, Wege des Besuchers zur Anfrage) |
| 1.3 | Beratung zu Inhalten: welche Informationen auf welche Seite gehören |
| 1.4 | Laufende Abstimmung in Feedback-Runden inklusive Einarbeitung der Änderungswünsche |

## 2. Gestaltung

| Pos. | Leistung |
|---|---|
| 2.1 | Individuelles Design im eigenen Look („Comedy aus einer anderen Galaxie") — keine Vorlage von der Stange |
| 2.2 | Festlegung von Farben, Schriften und Bildsprache als durchgängige Handschrift der Seite |
| 2.3 | Gestaltung jeder einzelnen Seite als Entwurf und Abstimmung mit dem Auftraggeber |
| 2.4 | Eigene Farbwelt je Show, damit die Programme auf einen Blick unterscheidbar sind |
| 2.5 | Darstellung auf Handy, Tablet und Computer — jede Seite in allen Größen gestaltet und geprüft |
| 2.6 | Bewegte Elemente und Effekte (Sternenhimmel, Bildwechsel, sanfte Übergänge beim Scrollen) |
| 2.7 | Rücksicht auf Besucher, die Bewegung reduzieren möchten: ruhige Variante der Seite |

## 3. Öffentliche Seiten

| Pos. | Leistung |
|---|---|
| 3.1 | **Startseite** mit Begrüßung, Show-Übersicht, nächsten Terminen und Bildergalerie |
| 3.2 | **Trailer-Bereich** auf der Startseite: großflächiges Video mit Ton-Schalter, startet erst beim Hinsehen |
| 3.3 | **Show-Übersicht** aller Programme |
| 3.4 | **Detailseite je Show** mit Beschreibung, Bildern, Videos, Mitwirkenden und den passenden Terminen |
| 3.5 | **Terminübersicht** mit Kalenderansicht, Listenansicht und Filtern (Show, Ort, Zeitraum) |
| 3.6 | **Landkarte der Spielorte** mit farbigen Markierungen und Direktverweis auf den Termin |
| 3.7 | **Ticket-Verweise** je Termin auf den jeweiligen Vorverkauf |
| 3.8 | **Bildergalerie** mit Filtermöglichkeit und Großansicht der Bilder |
| 3.9 | **Videobereich** mit Einbindung der YouTube-Clips |
| 3.10 | **Seite „Über Steffen"** mit Vorstellung, Bildern und Werdegang |
| 3.11 | **Auftritte & Partner** — Auflistung von Bühnen, Veranstaltern und Kooperationen |
| 3.12 | **Angebotsseite** für laufende Aktionen und Spar-Codes |
| 3.13 | **Kontaktseite** mit Erreichbarkeit und Verweisen auf die Social-Media-Kanäle |
| 3.14 | **Ein-Zeiler / Sprüche** als wiederkehrendes Element |
| 3.15 | Durchgängige Navigation und Fußbereich auf allen Seiten |

## 4. Anfragen & Kommunikation

| Pos. | Leistung |
|---|---|
| 4.1 | Anfrageformulare für Buchungen (Show buchen, Steffen buchen) und für Fragen/Feedback |
| 4.2 | Prüfung der Eingaben mit verständlichen Hinweisen, wenn etwas fehlt |
| 4.3 | Sichere Speicherung jeder Anfrage, damit nichts verloren geht |
| 4.4 | Automatische Bestätigungs-E-Mail an den Anfragenden im Design der Website |
| 4.5 | Automatische Benachrichtigungs-E-Mail an Steffen mit allen Angaben der Anfrage |
| 4.6 | Frei einstellbare Empfängeradressen je Formular — änderbar ohne uns |
| 4.7 | Übersicht aller eingegangenen Anfragen im Verwaltungsbereich |
| 4.8 | Einrichtung und Test des E-Mail-Versands, damit die Nachrichten zuverlässig ankommen und nicht im Spam landen |

## 5. Verwaltungsbereich („Mission Control")

Eigener, passwortgeschützter Bereich, in dem Steffen die komplette Website selbst pflegt — ohne Fachkenntnisse und ohne uns.

| Pos. | Leistung |
|---|---|
| 5.1 | Geschützter Zugang mit persönlichem Login |
| 5.2 | Startübersicht mit den wichtigsten Zahlen und offenen Anfragen |
| 5.3 | Shows anlegen, ändern, Reihenfolge und Sichtbarkeit steuern |
| 5.4 | Termine anlegen und pflegen — einzeln oder als Serie (wöchentlich, 14-tägig, monatlich) in einem Schritt |
| 5.5 | Spielorte auf der Landkarte per Klick anlegen und Terminen zuordnen |
| 5.6 | Mehrere Termine je Spielort in einem Formular erfassen, Stadt und Location werden automatisch übernommen |
| 5.7 | Bilder hochladen, zuschneiden und der Galerie oder einer Show zuordnen |
| 5.8 | Videos und Trailer hochladen und austauschen |
| 5.9 | YouTube-Clips verwalten |
| 5.10 | Mitwirkende Comedians pflegen und Shows zuordnen |
| 5.11 | Auftritte und Partner pflegen |
| 5.12 | Angebote und Aktionen mit Laufzeit anlegen |
| 5.13 | Ein-Zeiler und Sprüche pflegen |
| 5.14 | Rechtstexte (Impressum, Datenschutz, AGB) selbst bearbeiten |
| 5.15 | Einstellungen wie Benachrichtigungs-Adressen selbst ändern |
| 5.16 | Änderungen erscheinen sofort auf der Website — ohne weiteren Arbeitsschritt |
| 5.17 | Rückmeldungen und Sicherheitsabfragen vor dem Löschen |
